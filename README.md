# Origen - Café de Especialidad

Sitio web responsivo para una cafetería de especialidad, diseñado para ofrecer una experiencia visual atractiva y una navegación fluida a través de la identidad de la marca. La plataforma presenta la propuesta del negocio, su catálogo de productos y canales de contacto.

---

## Características y Secciones

* **Sección Principal / Inicio:** Presentación de la marca con una estética visual cuidada basada en la cultura del café.
* **Catálogo de Productos:** Visualización organizada de las variedades de café y productos disponibles.
* **Sucursales y Contacto:** Información de localización y horarios para los clientes.
* **Diseño Adaptable:** Maquetación totalmente fluida y optimizada para dispositivos móviles y pantallas de escritorio.

---

## Tecnologías utilizadas

* **HTML5 / CSS3:** Maquetación y diseño responsivo del sitio.
* **Sass (SCSS):** Organización de estilos modular mediante variables, mixins y anidamiento.
* **Bootstrap:** Framework para el diseño y maquetación de componentes.
* **Git:** Gestión del código.
